## 仓库边界

仓库保留当前维护文档、生产源码、行为回归测试、开发预览和构建脚本。临时内部评审、原始 QA 日志、旧版本方案、废弃原型和未选用资源不属于公开开发资料。

验证记录只说明对应版本和运行环境，不把模拟测试、原生探针和完整人工验收混为一谈。
