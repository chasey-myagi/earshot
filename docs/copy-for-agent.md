# 复制给 Agent

会话详情的常用操作为播放、「复制给 Agent」和更多菜单。更多菜单提供复制全文、导出 TXT、导出 JSON。

停止录音且有已确认文本后可复制。精修进行中也可复制；文件注明处理状态。剪贴板包含一句读取说明和本机绝对路径，接收端需要访问本机文件。不能访问本机文件的 Agent 可以使用「复制全文」。

首次复制路径时，在 `~/Library/Application Support/Earshot/sessions/<会话ID>/transcript.md` 生成可读稿。内容包含标题、开始时间、会话 ID、更新时间、处理状态、时间戳、说话人和正文，不包含密钥或其他会话的联系人。主进程原子替换文件，权限 0600。精修、说话人改名、会话标题变化及文字纠错或撤销后更新同一文件；退出应用仍可读取。文件与会话同目录，删除会话目录会一起删除。沿用已有的会话删除与撤销流程。

只对首次点击过复制路径的会议维护文件。复制全文不启用文件共享。传统导出仍是保存时的静态快照。后台写盘失败不影响录制/转写，会尝试移除失效副本并记通用错误日志；再次复制可重新生成。磁盘不可写且无法移除时，旧文件可能留存，应参考更新时间。

## 交互

- 复制成功原位显示勾号和「已复制」约 2.2 秒，按钮宽度固定。
- 复制失败就地播报错误，不显示成功。
- 使用 transitions.dev 的 menu-dropdown 和 icon-swap，保留 reduced-motion 规则。
- 菜单支持方向键、Home/End、Escape、Tab 离开和点击外部关闭；Escape 返回更多按钮。
- 切换会话卸载旧操作组件，清理计时器，旧异步结果不污染新会话。
