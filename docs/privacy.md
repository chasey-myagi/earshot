# 隐私与数据流

> 对应当前源码 · 2026-09-07

Earshot 没有账号、托管中继或自建遥测服务。云端识别使用用户自己的 DashScope 账户；它不是离线转写应用。

## 本机保存什么

正式应用通常使用 `~/Library/Application Support/Earshot/`，具体路径由 Electron `userData` 决定。

| 数据 | 保存与用途 |
| --- | --- |
| API 密钥 | `key`，明文，文件权限 `0600`；不使用 Keychain 或应用层加密 |
| 录会音频 | 每场会的 `mic.wav` 与 `system.wav`，用于回听和转写重试 |
| 稿件与会话信息 | 会话 JSON / JSONL、时间戳、标题、任务状态和本场名字 |
| 语音输入 | 保存识别原稿及最终文字；音频临时保留在内存供当前识别/重试 |
| 人物和声纹 | 全局名字及 CAM++ 向量，本机提取匹配 |
| 设置 | 自动区分、快捷键、插入方式和模型选择 |

`0600` 限制其他普通系统账户读取密钥，不能防止当前用户权限下的其他程序或管理员读取。录音和稿件同样没有应用层加密；磁盘备份和同步工具可能复制这些文件。

## 什么会离开本机

- 开始录会后，双轨音频通过 DashScope WebSocket 实时识别。
- 停录后，WAV 上传到 DashScope 返回的上传地址，再提交文件识别任务；启用自动区分时处理说话人分离。
- 语音输入通过 DashScope 流式接口发送麦克风音频。
- 开启可选文字润色时，识别文本发送到 DashScope 的兼容 Chat API；默认关闭。
- 安装依赖和下载可选声纹模型会连接 npm、Electron/GitHub 或模型下载托管服务。运行期声纹提取和匹配在本机完成。

Provider 端点和模型可在 `src/main/providers/`、`src/shared/model-settings.ts` 核对。API key 输入只经 preload 交给主进程；主进程向服务商鉴权，渲染快照仅返回是否已配置。应用不在默认日志主动记录密钥，但分享日志前仍应自行检查其中的路径、错误及内容。

服务商的数据保留、账单与使用条款由服务商决定；本项目不承诺其保存期限或删除结果。删除本机会话不会调用服务商数据删除接口。

## 权限与跨 App 输入

录会需要麦克风和屏幕/系统音频权限。语音输入使用麦克风，跨应用写文字需要辅助功能权限。应用通过 Accessibility 读取目标输入控件的文字和选区作安全比对；该目标文字不作为润色上下文发送给云端。仅选区替换，不模拟 Enter；目标变化或安全输入时拒写并保留结果供复制。

复制是用户触发的动作，文字会进入 macOS 剪贴板，可能被其他应用或系统剪贴板同步读取。

## 删除与反馈

会话删除在撤销期后移除本场目录；已经导出的文件和全局人物、声纹不会同时删除。需要完全移除本机数据时，停止录音并退出应用，再手动移除上述 `userData` 目录；这也会清除密钥和设置。

提交 Issue 时使用合成样例，移除密钥、私人录音、姓名、原始转录及本机路径。安全问题见 [SECURITY.md](../SECURITY.md)。
