# Earshot 0.1.0 — Apple Silicon Preview

macOS **26.4+**，Apple Silicon（arm64），中文界面。**开发签名、未公证的预览版**，不是稳定版；首次打开可能需要按 macOS 提示明确允许。当前只在 macOS 26.7 本机验证，其他系统版本及全新 Mac 安装仍未验证。

[下载附件](https://github.com/chasey-myagi/earshot/releases/tag/v0.1.0) · [安装与更新](../install.md) · [隐私说明](../privacy.md)

## 首版功能

- 麦克风与系统音频录制、实时转写、会后转写和说话人区分。
- 保存历史、命名、时间戳回听、0.75–2 倍速、TXT / JSON 导出。
- 本机搜索、单段修正和撤销、时间标记；导入 WAV/MP3/M4A，单文件上限 64 MiB、30 分钟。
- 按住快捷键语音输入，可选文字整理；自动填入统一为一次临时剪贴板粘贴，未确认时保留文字供检查或复制，不自动按回车。
- 个人热词、本机用量估算和尽力而为的跨会声纹匹配。完整 ZIP 包含 CAM++ 模型。

没有 Earshot 账号或中继。录音保存在本机，转写直连用户自己的北京 DashScope / 百炼账户，需联网并产生服务商费用。它不是离线转写应用。

## 安装与更新

下载 `Earshot-0.1.0-macos-arm64.zip` 和 `SHA256SUMS.txt`，核对哈希，解压后拖到“应用程序”。GitHub 的 Source code 不是安装包。用户无需 Node.js、npm 或另外下载模型。

默认 `⌃⌥R` 录会、按住 `⌥空格` 语音输入；等待浮窗显示可以说话再开口。Key 在设置填写，录会需要麦克风及系统音频权限，跨 App 填入另需辅助功能权限。关闭窗口后仍在菜单栏运行；更新前正常退出并备份私人数据。没有自动更新。

当前签名不包含 Apple 公证。对可信来源应用的首次打开操作见 [Apple 官方说明](https://support.apple.com/en-us/102445)；不建议全局关闭 Gatekeeper。

## 已知限制

- 仅 arm64。最低系统 26.4 来自包内 ONNX Runtime，已与 App 元数据统一；最低系统实机尚未验证，不支持宣称 macOS 12+。
- Codex、微信等实际输入，Space/全屏/多屏浮窗及部分权限异常场景仍未完成当前版本验收。输入目标检查不是原子操作，不能保证任意 App 或输入法均可靠。
- 识别会有误字，首次准备可能较慢。远场声纹认回率仍不足，不能保证认出每位说话人。
- 用户期间的新复制会保留；取消不能撤回已派发粘贴。崩溃或慢剪贴板 provider 可能导致原内容无法恢复，出现提醒时请检查剪贴板。
- Key 是本机权限 0600 的明文文件，未使用钥匙串。删除本机内容不代表删除服务商副本；详见隐私说明。

## 验证与版本来源

本次发布准备的全量自动测试 **696/696 通过**、0 跳过，类型检查通过。此前独立 Electron 的三类合成控件验证了一次粘贴、零 Enter 和剪贴板恢复，本机安装后旧会话和新版设置可见。这些结果不替代全新 Mac、互联网下载后首次打开或所有真实应用验收。

Release 标签指向完整源码；具体 commit、锁文件哈希、runtime/模型版本及 ZIP 哈希在附件 `release-manifest.json` 中。下载字节以 `SHA256SUMS.txt` 为准，源码以该标签归档为准。对应提交的远端检查在 Actions 可查。

源代码采用 MIT；包内附带第三方 runtime 与模型的独立许可证。问题反馈：[Issues](https://github.com/chasey-myagi/earshot/issues)；安全问题：[私密漏洞报告](https://github.com/chasey-myagi/earshot/security/advisories/new)。请使用合成示例，不上传 Key、私人录音或真实会话截图。

## English

Earshot 0.1.0 is an **unnotarized, development-signed Apple Silicon preview** for macOS **26.4 or later**. The interface is Chinese. Only macOS 26.7 was tested locally; other OS versions and installation on a fresh Mac remain unverified. Gatekeeper may require an explicit exception for this trusted-source preview; follow the linked Apple guidance rather than disabling security globally.

Record microphone and system audio, view live and post-recording transcripts, name speakers, search and correct local text, import recordings, and hold a shortcut to dictate. Recognition uses your own Beijing DashScope account and incurs provider charges. The full ZIP includes its runtime and local speaker-embedding model. There is no account, relay or automatic updater.

Cross-app dictation, fullscreen/Spaces, permission edge cases and far-field speaker matching retain known limitations. A canceled paste cannot be retracted, and clipboard recovery is not crash-proof. Read the installation and privacy guides. The release manifest binds the ZIP to its exact source commit and dependency/model versions.
