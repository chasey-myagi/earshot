# Earshot UI/UX 整理 · 2026-09-14

范围：实际 Electron/React App；以 public 工作区 aa05e2d + 原有 40 份修改的本地快照 553b8fb 为基线。原来的 v2 HTML 原型不再作为本轮交付。

## 依据与取舍

- 用户提供的历史任务：搜索叠压侧栏、命中重复标题、播放条拥挤、删除失败误显批量选择与含糊文案。
- PRODUCT.md / DESIGN.md：本机录音和回听，保留原稿，BYOK，默认关闭自动标题与文字整理。
- Transitions.dev：05 菜单开合、09 播放图标切换、22 删除通知；保留原始参数与减少动态效果规则，关闭期间取消交互，支持快速重新打开。
- Impeccable：polish / harden / ux-writing；检查层次、密度、键盘、失败反馈、滚动、长文案与边界。
- Libraries.dev：参考 Thinking Orbs 的紧凑状态标识、稳定控件尺寸和低对比表面；本地 SVG/CSS 状态环仅在加载时运行，不增加依赖。

## 界面清单

| 界面/流程 | 整理结果 |
| --- | --- |
| 启动 | 可读的加载提示；读取失败保留已有会话，提供重新加载；忽略过期请求 |
| 首次使用 | 统一“录音”文案，说明麦克风/系统声音；密钥输入支持 Enter、错误关联；外链/权限打开失败就地提示 |
| 会话列表 | 类型筛选、单选/多选/范围选择、双击/Enter 改名；搜索时使用同一侧栏空间；更明显的滚动条 |
| 搜索 | 标题按会话分组，片段显示说话人和时间；关键词高亮；⌘F、Esc、方向键；无结果/失败/50条上限；点击定位回听 |
| 会话管理 | 标题与列表共享删除中的状态，同一会话重复点击只发一次请求；单次错误与多选分离；删除后可撤销，恢复失败保留提示 |
| 转写阅读 | 正文为主，段落编辑移到悬停/键盘聚焦；仍显示手动修改标记；录中上翻不抢滚动，历史稿不显示“回到最新” |
| 改稿/说话人 | 单段编辑与整组改名分开；输入、保存、取消、撤销、恢复原稿；原始文字保留 |
| 回听 | 标题、居中播放/前后5秒、倍速/结束一行，独立进度行；加载/暂停/错误/结束清楚区分；控制保持稳定尺寸 |
| 导出 | 菜单有入退场与键盘返回焦点；TXT/JSON；在 Finder 显示失败改为页内提示 |
| 录音/处理 | 准备、录制、停止/重试保存、断线/重连、异步处理/取消反馈；录中浮窗与完整稿入口 |
| 录音标记 | 添加当前位置、命名、回听、删除与空状态；保留原有逻辑 |
| 快捷键 | 捕获超时/失焦清除提示；系统注册失败不会被“已保存”遮住；保存防重复 |
| 语音输入 | 状态环/声级、60秒可见上限、临近上限倒计时；转写到上限原因可读；复制/重试/关闭有失败与成功反馈 |
| 语音输入文档 | 原始口述、整理稿、手动修改、复制、导出；长文有滚动提示 |
| 录音设置 | 开关等待实际保存结果；失败提示且不假装已生效；保留自动标题默认关闭与原生成条件 |
| 热词 | 保留用户草稿；读取失败可直接重试；保存/同步失败区分；解释发送目的与停用行为 |
| 用量/费用 | 时间范围、刷新、空状态/失败和估算口径；账单入口失败反馈 |
| 全局 | 深浅色、焦点可见、禁用原因、低动态偏好；主区按弹出的通知自然分配空间，避免覆盖播放器 |
