# 验证

## 自动检查

```sh
npm ci
npm run typecheck
npm test
npm run build
npm audit
```

测试以合成数据验证存储、录制生命周期、实时重连、异步任务恢复、回听、导出、命名、删除、语音输入状态机、快捷键设置和受保护的输入目标。OS 与云端边界使用替身，测试通过不等于真机通过。

## macOS 手动检查

| 功能 | 需要观察的结果 |
| --- | --- |
| 首次权限 | 麦克风、屏幕/系统音频与辅助功能授权状态准确，拒绝后有恢复入口 |
| 双轨录会 | 麦克风与已知系统声音实际进入对应 WAV，停录后可回听 |
| 实时与会后稿 | 录中有文字，断网不损坏音频，恢复后可继续或重跑 |
| 窗口与回听 | 关闭/切换窗口不丢录制控制，时间戳跳转对应原声 |
| 物理快捷键 | 按住收音、松开结束；切走输入目标后拒写，结果可复制 |
| 跨 App 回填 | TextEdit 等普通控件只替换选区，保留前后文字及 emoji |
| 本地安装 | 打包签名通过，安装后启动正常，旧会话与设置可读 |

以上是验收步骤，不是所有环境已经通过的声明。Intel Mac、全屏空间和外接显示器浮窗尚未验证。
